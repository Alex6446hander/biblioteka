# Анализ макета и UI Kit

## Макет сайта (Левая часть)
- **Заголовок:** "СУД - Система управления документами"
- **Кнопки действий:** "Войти", "Регистрация"
- **Hero-секция:** 
    - Заголовок: "Система управления документами"
    - Описание: "Надёжное хранение документов, контроль доступа и умная архивация"
    - 3 буллита:
        - Упорядоченный учёт документов
        - Разграниченная передача прав доступа
        - Автоматическая архивация и удаление по срокам
    - Кнопка: "Войти в систему"
- **Секция преимуществ:**
    - Контроль доступа (Любой пользователь может иметь доступ только к тем документам, которые ему разрешены)
    - Автоматизация (Автоматическая архивация и удаление по срокам)
    - Безопасность (Надёжное хранение данных и прозрачность передачи документов и сведений)
    - Полный аудит действий (Полная история действий для прозрачности и контроля)
- **Футер:** "СУД — Система управления документами", "2024"

## UI Kit (Правая часть)
- **Форма входа:** 
    - Табы: "Войти", "Регистрация"
    - Поля ввода: "Логин", "Пароль" (с иконкой видимости пароля)
    - Кнопка "Войти" (синяя)
    - Ссылка "Зарегистрироваться"
- **Состояния уведомлений:**
    - Успешный вход (зеленое уведомление)
    - Ошибка (красное уведомление с кнопкой закрытия "x")
    - Пример ошибок: "Неверный логин или пароль", "Аккаунт заблокирован, выйдите"
- **Стилизация:**
    - Синие акцентные кнопки
    - Светлые поля ввода с серыми рамками
    - Красные уведомления об ошибках
    - Контрастный текст на светлом фоне
